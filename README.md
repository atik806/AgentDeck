# AgentDeck

**Downloads have moved to [atik806/AgentDeck-releases](https://github.com/atik806/AgentDeck-releases/releases/latest).**

This repository exists for one reason: AgentDeck builds up to **v0.30.0** look
here for their updates. It carries the v0.30.1 release so those builds can find
it and update themselves — after that they follow the new location on their own.

No source code lives here, and it is never the place to get a current build.

- **Download AgentDeck:** <https://vibeflow.tech/agentdeck>
- **Releases:** <https://github.com/atik806/AgentDeck-releases/releases/latest>

If your in-app Update button reported a `404`, install the current version once
from either link above and updates will work again from then on.
